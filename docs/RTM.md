# Requirements Traceability Matrix (RTM) - test status

Replaces the status column of SRS section 8 (see docs/DEVIATIONS.md). Generated by `python scripts/generate_rtm.py`, which runs the automated tests and marks a requirement **P** only if every test file listed for it passes.

Status: **N** = not tested, **P** = passed, **F** = a mapped test failed, **A** = tested and approved (set by the QA Lead after sign-off).
